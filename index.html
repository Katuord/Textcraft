ガイド & アップデート

使い方、便利な操作、バージョン情報をまとめています。

VERSION 3.3
QUICK START · 3 STEPSアイデアを、すぐにデザインへ。

まずはテキストを置いて、見た目を整え、画像として書き出してみましょう。

01プロジェクトを作る

「新規プロジェクト」で作品名とキャンバスサイズを選びます。迷ったら16:9から始めましょう。

02素材を追加する

左の「テキスト」「図形」「画像」から追加。キャンバス上でドラッグして位置を調整できます。

03装飾して書き出す

右の「基本・装飾・配置」で編集。完成したら右上の「書き出し」でPNGやWebPに保存します。

最初に試すなら 「テキスト」→文字を入力→「装飾」でグラデーション→「書き出し」の順がおすすめです。
✦
文字・フォント

529種類のフォントライブラリ、文字間隔、行間、二重縁取り、立体、影、発光、背景プレートに対応。フォントはネット接続時に読み込みます。

◈
グラデーション

複数色ストップと透明度ストップを自由に追加・移動できます。色見本の「COLOR MOOD LIBRARY」は見出しを押して折り畳みできます。

T
テキスト診断・復旧

上部ツールバーの「T テキスト診断」で、非表示レイヤーや非表示フォルダー、空テキスト、透明度による見えにくさを確認できます。表示復旧は確認してから実行します。

▰
フォルダー・レイヤー

Ctrl / ⌘ を押しながら複数選択し、Ctrl / ⌘ + G でフォルダー化。フォルダーの中にフォルダーを作れます。ドラッグで階層移動もできます。

◐
マスク・切り抜き

切り抜かれる側を選び、「マスク元レイヤー」で図形・文字・画像を指定。内側を残す／重なりをくり抜くを切り替えます。

▶
Animation Studio

レイヤーを選択してキーフレームを追加。プロパティにチェックを入れ、時刻を移動して値を変更します。GIF書き出しにはインターネット接続が必要です。

作品はどこに保存される？

編集中の変更は、このブラウザのLocalStorageに自動保存されます。同じブラウザ・同じ端末で使えますが、別端末へは同期されません。

バックアップを作るには？

右上の「プロジェクト保存」で .typecraft ファイルをダウンロードしてください。別の端末やブラウザでは「プロジェクト読込」から読み込めます。

フォントが変わらない・読み込めない

フォントはGoogle Fontsから読み込むため、ネット接続やブラウザの制限によって代替フォントになる場合があります。右上のフォント状態表示も確認してください。

古いプロジェクトは使える？

旧バージョンの .typecraft / JSON の読み込みに対応しています。大切な作品は、読み込み前に元ファイルを残しておいてください。

画像を書き出すには？

PNGは透過に対応、WebPはファイルサイズを抑えられます。SVGは現在、PNG画像を埋め込む形式です。
